# Toward Optimal Adenovirus Detection Using YOLO26

Python scripts for benchmarking baseline and modified YOLO26 object detectors for adenovirus detection in transmission electron microscopy (TEM) images.

## Contents

- Baseline YOLO26 benchmark
- Modified YOLO26 benchmark
- Dataset configuration

## Requirements

- Python 3.x
- PyTorch
- Ultralytics YOLO26
- OpenCV
- NumPy
- pandas
